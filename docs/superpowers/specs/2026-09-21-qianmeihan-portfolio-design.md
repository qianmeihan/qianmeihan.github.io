## 内容模型

编辑器管理一个站点配置文件，字段同时包含中文和英文版本：

- 基本信息
- 首屏文案
- 职业概述
- 工作经历列表
- 工程案例列表
- 专利列表
- 技能分组
- 教育经历列表
- 图片与图片来源
- 联系链接

每个可重复内容块都有稳定标识，避免中英文列表错位。公开网站在浏览器中切换语言，不重新加载页面。语言选择保存在浏览器本地，首次访问默认使用浏览器语言。

## 技术架构

- 静态网站生成：Vite 和 React
- 样式：项目自有 CSS 变量与响应式布局，不引入默认主题外观
- 图标：统一使用一个成熟图标库
- 内容：Git 可追踪的 JSON 文件
- 编辑：Sveltia CMS 管理 JSON 与图片
- 发布：GitHub Actions 构建并部署到 GitHub Pages
- 路由：公开页面 `/`，编辑器 `/admin/`

网站不需要数据库、服务端会话或访客登录。公开内容与网站源码位于公开仓库，因此不得把任何秘密、Token 或敏感资料写入内容文件。

## 视觉系统

视觉定位是“精密机械档案”，延续参考站点清晰的侧边导航和单页浏览方式，但不复制其版式细节。

- 主色：石墨黑与深冷灰
- 背景：柔和白和铝银灰
- 单一强调色：低饱和精密绿色
- 字体：现代无衬线字体，中英文均保持清晰和专业
- 形状：卡片使用统一的轻微圆角，按钮保持同一圆角规则
- 布局：桌面端采用窄侧边导航和宽内容区，移动端改为紧凑顶部导航
- 图片：首屏职业照、专利图、真实产品或制造场景图片
- 动效：只使用进入、悬停和语言切换所需的轻量动效，并尊重减少动态效果设置
- 主题：支持亮色、暗色和系统偏好，所有页面保持同一主题逻辑

首屏必须在常见笔记本视口内完整展示姓名、定位、简短概述和主要联系入口。

## 可访问性与隐私

- 正文默认字号不小于 16px。
- 文本和按钮达到 WCAG AA 对比度。
- 所有图片提供与内容相关的中英文替代文本。
- 导航、语言切换、主题切换和链接支持键盘操作与明显焦点状态。
- 页面不使用追踪脚本、广告或第三方分析服务。
- 外部链接明确标识并使用安全的新窗口属性。
- 邮箱公开，电话继续隐藏。

## 错误与回退

- 内容字段缺失时隐藏相应模块，不显示空卡片或占位文字。
- 网络图片加载失败时保留固定尺寸和替代文本，避免页面跳动。
- 编辑器认证失败时显示明确的 GitHub 权限提示，不缓存无效凭据。
- GitHub Pages 构建失败时保留上一版本，不把未完成页面发布给访客。
