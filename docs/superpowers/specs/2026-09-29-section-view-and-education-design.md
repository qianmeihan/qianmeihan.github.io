# 单页模块切换与教育经历扩展设计

日期：2026-09-29

## 已确认的意图

网站继续使用同一个地址和现有左侧（手机端顶部）导航。点击一个模块时，右侧主内容区只呈现该模块；每个模块占据完整的主内容展示区域，不再把所有模块纵向堆在同一长页上。这里的“一个页面”指同页内切换视图，不是新建 HTML 页面或新 URL 路径。概述为默认视图。长内容可以在当前视图内正常纵向滚动。

## 方案选择

采用基于 URL hash 的单页视图切换，例如 `#education`。这保留了现有链接形式，支持直接分享、刷新、浏览器前进与后退。导航始终可见，选中的模块继续高亮；切换后主内容从顶部开始。保留原有中英文、亮暗色、简历下载与公开专利链接。各模块不再同时渲染到主内容区。

备选方案是保留所有模块在 DOM 中并使用整屏滚动吸附，但它仍依赖页面长滚动，且内容长短不一，不能准确实现“点击后只看这个模块”，因此不采用。

## 信息架构与页面状态

- 模块：概述、教育经历、工作经历、代表项目、专利、专业能力、产品领域、联系。
- `#profile` 是概述；无 hash 或未知 hash 时显示概述。
- 侧栏品牌和“返回概述”指向 `#profile`；概述内“了解更多”打开教育视图，“联系我”打开联系视图。
- 仅活动模块出现在主内容中；每个视图保留清晰的标题层级和可访问的导航状态。
- 视图至少占据可用主内容高度，但不把长内容硬塞进单个视口。手机端使用现有顶部导航，内容纵向排列，不出现横向溢出。

## 教育视图内容

教育视图先于其他模块扩展内容，但仍围绕求职相关的机械设计、材料与产品开发能力。两所学校分开展示校徽、学校名、真实学位/学习路径、时间和精选课程：

- 东北大学：材料科学与工程学士。课程候选来自本人东北大学成绩单：工程图学基础、材料力学、动力学、机械工程、材料性能、计算机辅助设计（CAD）。页面只取适量课程，不展示课程成绩。
- 图卢兹第三大学：根据本人法方学位证明，表述为机械学学士（航空机械工程方向），而非仅“机械工程双学位经历”。法方材料明确对应 2021/2022 学年，时间应采用 2021-2022，避免误示在法学习四年。课程候选来自本人法方成绩单：机械学、连续介质力学、机械设计、材料、制造工艺、结构与制造；中英文名称按原法语课程语义翻译。
- 可链接学校/项目的公开官方网页作背景来源，但不上传、链接或公开原始成绩单、分数、绩点、学号、出生信息、证件信息。
- 现有材料与公开网页没有证明某位教师是钱美含本人的导师。不得把学校教师、系主任、课程负责人推断成个人导师。若日后本人提供可核对的姓名和关系，再考虑添加导师信息。

## 数据与编辑器

教育扩展内容继续保存在 `public/content/site.json`，沿用双语字段、内容校验与本地可视化编辑器，不引入 CMS 或公开写入能力。新增教育字段应是可编辑、可校验的普通内容，而非写死在组件中的私有数据。

## 验收

1. 点击每个导航项只显示对应模块，且活动态正确。
2. 直接访问 `#education`、刷新与浏览器前进/后退均恢复正确模块。
3. 概述 CTA、品牌、页脚导航均指向正确模块。
4. 中英文与主题切换不丢失当前模块。
5. 教育视图课程、学位、时间准确且没有私人证件/成绩数据。
6. 桌面与手机无内容截断或横向溢出；键盘与屏幕阅读器可识别当前模块。
7. 单元测试、构建、浏览器测试通过后再发布到现有 GitHub Pages。
